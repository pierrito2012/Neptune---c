# Neptune --c

**Neptune -- C** é uma linguagem de programação **interpretada, procedural e sem tipagem**.

A linguagem está atualmente em desenvolvimento. Ela já possui diversos recursos para programação, mas **podem existir bugs**, principalmente relacionados à compatibilidade com algumas IDEs e ambientes.

Se você testar a linguagem, fique à vontade para deixar comentários, sugestões e dizer o que achou. Isso ajuda bastante no desenvolvimento do Neptune.

---

## 📦 Instalação

### 1. Baixe o projeto

Depois de baixar ou clonar o repositório, entre na pasta do Neptune:

```bash
cd Neptune
```

Depois entre na pasta do instalador:

```bash
cd Neptune_Universal_Installer
```

Execute o instalador:

```bash
./install_neptune.sh
```

O instalador irá configurar o Neptune e a IDE.

---

## 💻 Como programar em Neptune

O Neptune pode ser utilizado de duas formas:

* Pelo **terminal**, utilizando o modo de código.
* Através de **arquivos `.nep`**.

---

## 📄 Programando com arquivos

Os programas Neptune utilizam a extensão:

```text
.nep
```

Por exemplo:

```text
meu_programa.nep
```

Para executar um arquivo pelo terminal:

```bash
neptune /meu_programa.nep
```

---

## 🖥️ Modo Terminal

Também é possível utilizar o Neptune diretamente pelo terminal.

Digite:

```bash
neptune --c
```

Isso abrirá o **modo de código do Neptune**, permitindo escrever e executar código diretamente pelo terminal.
