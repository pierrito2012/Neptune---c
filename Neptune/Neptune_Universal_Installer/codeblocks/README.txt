Code::Blocks:
There is no single portable user lexer-install path shared by all Code::Blocks releases.
This package contains Neptune keywords and a run command, but does not overwrite global
Code::Blocks lexer files.

Use a C/C++/Lua-like lexer if your installation offers one, or add Neptune through the
editor's own syntax/lexer configuration when supported.
Run command:
neptune "%f"
